# 测试策略与可复现性

生产实现和 oracle 使用不同的方法。生产图秩为 DSU，Python 用路径可达判断每条边是否产生环；生产匹配用增广路径，Python 枚举右侧注入赋值；生产 GF(2) 用主元消元，Python 枚举 XOR 闭包后取维数；配额模型用所有可行子集的最大大小定义秩。随机种子固定为 20261111，测试样本和期望由仓库工具再生成，生成测试不计生产行数。

三元素秩表从所有基数界内表枚举，再用**所有对子集**的单调性、次模性筛选，得到 16 个带标签拟阵；求交对 256 组穷举共同独立子集，与 BFS 结果及证书比较。六类模型各 8 组，6 个元素的每个子集均核对秩；加权最优值从所有独立集/基直接枚举得到。并集对每个元素的“不选/分配给模型一/分配给模型二”三种状态穷举，与分解输出比较。

核心回归还包括：重复/越界 ID、构造输入副本、自环/平行边/空模型、GF(2) 最高位、层次交叉集合、坏秩表、负权与 Int32 极值、贪心失败实例、预算不足、伪造证书、分解重叠、秩快照损坏和非规范数字。对偶两次、删除收缩对偶与 Tutte 对偶网格用作代数关系验证；它们不替代独立秩答案。

运行 `moon info`、`moon fmt --check`、四后端各自 `moon check/build/test --target TARGET --deny-warn` 与三个例子。生成器复现用 `python tools/oracle.py` 后 `moon fmt` 与 `git diff --exit-code`。测试样本数量见 [oracle-metrics.json](competition/oracle-metrics.json)。

没有测量分支覆盖率、峰值内存或跨库性能，不能从通过数量推断所有输入均正确。枚举与最优性证明仅在文档给定范围内工作。
