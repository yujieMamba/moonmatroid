# 行为模型与验收设计

地集是稳定编号 0..n-1，n<=64。所有集合输入拒绝重复与越界，不隐式合并。构造函数复制输入；返回集合不共享内部存储。组合操作保留或显式重编号地集。

1. 六类精确秩模型：均匀、划分、图、二元线性、横截、层流容量；另有小地集秩表完整公理校验。
2. 秩、独立性、基、闭包、回路、基本回路、基本割集与变换；整数权重贪心不等于带权拟阵交。
3. 无权拟阵交使用最短增广路，返回共同独立集和可独立核对的 Edmonds 秩和上界证书。预算耗尽是错误，不是最优。
4. 拟阵并通过拟阵交归约，附分解见证；小规模穷举、秩生成/Tutte 系数和严格秩快照互操作受预算约束。
5. 三条完整下游流程：双配额选取、带类别限制的无环网络、GF(2) 特征去冗余与收缩分析。

所有核心算法以手写 MoonBit 实现，不调用 Python 或系统工具。Python 仅用于独立穷举验证。参考 SageMath 的公开数学行为，不复制 GPL 实现或测试。

非目标：任意未验证用户 oracle、浮点域拟阵、带权拟阵交、一般整数规划、无限规模、ZDD/FCA/定理证明。错误、空地集、零秩、loop/coloop、平行边和退化矩阵必须测试。
